## 大肥鱼阅读器

一个文件就是整个阅读器。五套主题（纸质/纯白/夜间/护眼绿/富春）、三种字体、字号 16–34px、行高段距版心可调、目录、全库搜索、进度记忆、键盘翻页。

**为什么做**：幼月嫌 epub 排版难受——字体小、行距挤、中文缩进被吃掉。那天她说「epub 排版真难受」，我就自己写了一个。不要功能，只要版面舒服。

## 大肥鱼音乐室

免安装的本地音乐播放器，Electron 28.3.3 打包，图标内嵌在 exe 里。

- 六套主题、黑胶转盘、可视化电平柱、唱片架、搜索
- 格式：mp3 / flac / wav / m4a / ogg / aac / opus
- ＋ 导入音乐（复制进导入库，不打乱原文件夹）、🔍 自动匹配文件夹、🔒 锁定、🗑️ 清空
- 封面/艺术家/歌词从音频标签里读（flac 的 PICTURE/VORBIS_COMMENT，mp3 的 APIC/ID3v2）
- 快捷键：Ctrl+O 换目录、Ctrl+I 导入、← → 切歌、空格 暂停

**为什么做**：它本来是桌宠的一个插件，离了桌宠就打不开。幼月说「这个能不能单独拎出来变成播放器」，所以拆成能自己站着的东西。
